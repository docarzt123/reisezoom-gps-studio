# Reisezoom GPS Studio — Logo-Konzept

Das Zeichen kombiniert drei sofort erkennbare Elemente:

- eine GPS-Route als durchgehende Bewegung,
- einen Standort-Pin als räumlichen Bezug,
- ein Play-Symbol für das Ergebnis nach der Tour.

## Varianten

- `gps-studio-logo.svg`: Reisezoom-Orange `#FF6B35`, transparenter Hintergrund.
- `gps-studio-watermark-white.svg`: einfarbig weiß, transparenter Hintergrund.
- `gps-studio-logo-2048.png`: PNG-Export mit Transparenz.
- `gps-studio-watermark-white-2048.png`: PNG-Wasserzeichen mit Transparenz.
- `gps-studio-watermark-preview-dark.png`: reine Vorschau auf dunklem Grund.

## Empfohlener Einsatz

- App und Website: Logo links neben dem Wortbild „Reisezoom GPS Studio“ in Manrope Semibold.
- Video-Wasserzeichen: weiße Variante, 4–6 % der Bildbreite, 72–82 % Deckkraft,
  Abstand zum Rand mindestens die halbe Zeichenbreite.
- Kleine Größen: nur das Zeichen, ohne Wortbild. Mindestgröße 24 px.

Vor einer endgültigen Markenfestlegung sollte eine Ähnlichkeits- und Markenrecherche
erfolgen. Der Entwurf ist ein Arbeitskonzept, keine rechtliche Freigabe.
